implemented 항목은 실행 가능한 검증과 언어별 문서 쌍이 필요하며 partial과 planned는 미완료 상태다.

릴리스 후보 0.0.12의 매니페스트와 네이티브 lock 파일은 동기화했다. 기존 배포 파일 후보 9개는 현재 SDK 수정 이전의 산출물이므로 다시 빌드하고 검증해야 한다. 후보는 공개하지 않았다.

원격 main fcca660d의 CI 40439038565는 worker job 11개가 통과하고 scripts의 parity-check만 실패했으며 gates 40439038438은 공개 API 선언 누락 424건을 보고했다. 현재 SDK 계약/가시성 수정은 해당 커밋 자체에서 새 전체 CI 검증이 필요하다. 개발 검증은 PHP 8.4.27을 사용하며 라이브러리 요구사항은 >=8.4.0(표기 >=8.4)을 유지하고 Windows 설치 기준은 8.4.27-1이다. 이 템플릿 릴리스 조건을 외부 요인만 기다리는 상태로 분류하지 않는다.
