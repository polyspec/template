Scope precedence

A template definition receives root assign data, definition data and a scope argument, while a layout local stays isolated.

assign datadefine datascope precedencelocal isolation

Inputs

assign
{
  "page": {
    "title": "from assign"
  },
  "root_label": "root assign",
  "defined_label": "root value that is replaced"
}
define
{
  "layout": "layout.tpl",
  "content": {
    "template": "content.tpl",
    "data": {
      "title": "from define data",
      "defined_label": "definition data"
    }
  }
}
templates · parser ranges
--- content.tpl
<article>
<h1>{= title}</h1>
<p class="root">{= root_label}</p>
<p class="defined">{= defined_label}</p>
<p class="local">{= layout_local | default('missing')}</p>
</article>


--- layout.tpl
{layout_local = 'visible only in layout'}
<section class="scope">
{# content title:page.title}
</section>
